# UX改善計画書: 雪の降らない聖夜に

**作成日**: 2024-12-24
**目的**: ノベルゲーム×位置情報×歩数の融合UX最適化

---

## 1. 現状分析

### 1.1 現在の画面構成

```
index.tsx (スプラッシュ)
    ↓
opening.tsx (プロローグ)
    ↓
main.tsx ← メイン画面 (GPS背景 + キャラ + チャット統合)
    │
    ├── map.tsx (スポットマップ)
    │   └── spot/[id].tsx → event.tsx → main.tsx
    │
    ├── status.tsx (ステータス詳細)
    ├── chat.tsx (スタンドアロンチャット)
    ├── gallery.tsx (エンディングギャラリー)
    └── settings.tsx (設定)
    ↓
ending.tsx → share.tsx (エンディング)
```

### 1.2 モバイル独自機能の実装状況

| 機能 | 実装状況 | 可視性 | 改善点 |
|------|----------|--------|--------|
| **GPS位置情報** | ✅ useNearestSpot (500m閾値) | ⚠️ バッジのみ | スポット接近通知なし |
| **歩数カウント** | ✅ Pedometer連携 (100歩=1pt) | ❌ status.tsx内のみ | メイン画面に非表示 |
| **距離計算** | ✅ Haversine公式 | ⚠️ マップ画面のみ | 目的地までの距離なし |
| **時間制限** | ✅ 9時間カウントダウン | ✅ 常時表示 | 良好 |

### 1.3 競合分析

#### Pokemon GO型
- 「止まって操作」モデル
- 現在地から目的地へ移動 → 到着でイベント発火

#### Pikmin Bloom型
- 「歩くだけで報酬」モデル
- バックグラウンドで歩数カウント
- 日常の延長としてゲーム化

#### Mystic Messenger型
- リアルタイムチャット
- 時間限定イベント
- キャラクターとの関係構築

**当アプリの位置づけ**: Pokemon GO + Mystic Messenger のハイブリッド

## 2. 改善提案

### 2.1 歩数の可視化強化 [優先度: 高]

**問題**: 歩数がstatus.txsに隠れており、歩くモチベーションが弱い

**改善案**:

```
main.tsx に歩数ウィジェットを追加:

┌─────────────────────────────────┐
│ [Menu]  12:34   残り 5:32:10    │  ← 現状
├─────────────────────────────────┤
│ 📍 駅前マーケット 120m          │  ← 現状
│ 🏆 450pt  ❤️❤️❤️🤍🤍           │  ← 現状
├─────────────────────────────────┤
│ 👟 1,234歩 (+12pt)              │  ← 【NEW】歩数表示
│ ████████░░ 1,234/2,000歩        │  ← 【NEW】次のボーナスまで
└─────────────────────────────────┘
```

**実装ポイント**:
- useActivityTracking フックの戻り値を main.tsx で使用
- 100歩ごとにアニメーション（+1pt）
- 1000歩、5000歩などのマイルストーンで祝福演出

### 2.2 スポット接近通知 [優先度: 高]

**問題**: 500m以内にいても能動的にマップを見ないと気づかない

**改善案**:

```typescript
// useNearestSpot.ts の拡張
interface NearestSpotResult {
  nearestSpot: SpotInfo | null;
  timeOfDay: TimeOfDay;
  // 追加
  isApproaching: boolean;  // 200m以内に入った瞬間
  isInRange: boolean;      // 50m以内（チェックイン可能）
}
```

**UX実装**:
1. **200m以内**: かおりが「...あ、近くに何かある...？」と発話
2. **50m以内**: バイブレーション + 「ここ、チェックインできそう」
3. **到着後**: 自動で spot/[id].tsx への遷移ボタン表示

### 2.3 かおりの歩数反応 [優先度: 中]

**問題**: 歩数とキャラクターの関係性が希薄

**改善案**:

```typescript
// getKaoriDialogue を歩数対応に拡張
const getKaoriDialogue = (
  timeRemaining: number,
  lastActiveMinutes: number,
  checkInCount: number,
  expression: KaoriExpression,
  stepsToday: number  // 追加
): string => {
  // 歩数ベースのコメント
  if (stepsToday >= 10000) {
    return '...すごい、たくさん歩いたね...わたしも楽しい';
  }
  if (stepsToday >= 5000) {
    return '...なまら歩いた...足、大丈夫？';
  }
  if (stepsToday >= 1000) {
    return '...いい感じに歩けてる...';
  }
  // 既存のロジック...
};
```

### 2.4 メイン画面の情報設計 [優先度: 高]

**現状の問題**:
- スコアと好感度は表示されている
- 歩数、距離、次のスポットまでの情報が不足

**改善後のレイアウト案**:

```
┌─────────────────────────────────────┐
│ ☰ メニュー         12:34          │
│                残り 5:32:10        │
├─────────────────────────────────────┤
│ 📍 駅前マーケット                  │
│    120m ← 歩いて 約2分             │ ← 距離と時間
├─────────────────────────────────────┤
│                                     │
│      [かおりのキャラクター]         │
│                                     │
├─────────────────────────────────────┤
│ 🏆 450pt    ❤️❤️❤️🤍🤍    👟 1,234 │ ← コンパクトなステータスバー
├─────────────────────────────────────┤
│ ┌───────────────────────────────┐  │
│ │ 「...えへへ、今日は楽しいね」 │  │
│ └───────────────────────────────┘  │
│ [テキスト入力                   送信]│
└─────────────────────────────────────┘
```

### 2.5 ゲーミフィケーション強化 [優先度: 中]

**提案する新機能**:

1. **歩数チャレンジ**
   - 1時間ごとの歩数目標（500歩）
   - 達成でボーナスポイント + かおりの特別セリフ

2. **距離マイルストーン**
   - 累計1km、3km、5km達成で好感度ボーナス
   - 「...一緒にたくさん歩いたね」

3. **探索ボーナス**
   - 新しいエリアに入った時（初訪問地域検出）
   - 「...ここ、初めて来た...」

### 2.6 画面遷移の最適化 [優先度: 低]

**削除候補**:
- `home.tsx`: main.tsx と機能が重複 → 削除または統合

**遷移フロー簡略化**:
```
現状: main → map → spot/[id] → event → main
改善: main → 自動検出 → event → main (ワンステップ削減)
```
