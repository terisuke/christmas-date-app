# マルチシナリオ仕様書: 雪の降らない聖夜に

**作成日**: 2024-12-24
**バージョン**: 1.0
**ステータス**: 計画中

---

## 1. 概要

### 目的
好感度とスコアの両方を活用した、奥深いマルチエンディングシステムを構築し、プレイヤーに繰り返しプレイする動機を与える。

### 現状の問題点
- エンディングがスコアのみで決定（好感度が影響しない）
- 各エンディングの演出が薄い（固定メッセージのみ）
- シナリオの分量が少ない（テキスト量が物足りない）

### 目標
- 好感度（1-5）× スコア閾値（4段階）= **最大20通りのバリエーション**
- 各エンディングに固有のシナリオ演出
- テキスト量を現行の**3-4倍**に拡充

## 2. エンディング分岐システム

### 2.1 分岐マトリクス

| 好感度 | スコア<600 | スコア600-1199 | スコア1200-1799 | スコア≥1800 |
|--------|-----------|----------------|-----------------|-------------|
| **1** | BAD END A | NORMAL END A | - | - |
| **2** | BAD END B | NORMAL END B | GOOD END A | - |
| **3** | BAD END B | NORMAL END C | GOOD END B | - |
| **4** | - | NORMAL END D | GOOD END C | GOOD END D |
| **5** | - | NORMAL END E | GOOD END E | **TRUE END** |

※ 好感度4以上でBAD ENDは発生しない（プレイヤーの努力を報いる設計）

## 3. エンディング別シナリオ詳細

### 3.1 BAD END A: 「すれ違いの終わり」

**条件**: 好感度1 + スコア<600

**シナリオ概要**:
かおりはずっと距離を感じたまま。最後まで敬語で、心を開くことができなかった。

**ダイアログ（約10ステップ）**:
```
[ナレーション] 夕暮れの駅前。かおりを見送る時間が来た。

[かおり/shy] ...今日は、ありがとうございました

[ナレーション] 彼女の声は、朝と変わらない丁寧な響き。

[かおり/neutral] ...お兄さんのおかげで、福岡を見られました

[かおり/neutral] ...えっと、それでは...

[ナレーション] 何か言いたそうに口を開きかけて、でもすぐに閉じてしまう。

[かおり/sad] ...さようなら

[ナレーション] 彼女は小さく頭を下げると、改札の向こうに消えていった。

[ナレーション] 結局、本当の笑顔を見ることはできなかった。

[ナレーション] きっと、何かが足りなかったんだ...
```

**演出**:
- 背景: 夕暮れの駅（オレンジ → グレー）
- BGM: 切ないピアノ曲
- エフェクト: フェードアウト時に雪のエフェクト

## 4. 実装仕様

### 4.1 エンディング判定ロジック

```typescript
type EndingType =
  | 'BAD_A' | 'BAD_B'
  | 'NORMAL_A' | 'NORMAL_B' | 'NORMAL_C' | 'NORMAL_D' | 'NORMAL_E'
  | 'GOOD_A' | 'GOOD_B' | 'GOOD_C' | 'GOOD_D' | 'GOOD_E'
  | 'TRUE';

function getEndingType(score: number, affection: number): EndingType {
  // TRUE END: 好感度5 + スコア1800以上
  if (affection === 5 && score >= 1800) return 'TRUE';

  // GOOD END D: 好感度4 + スコア1800以上
  if (affection === 4 && score >= 1800) return 'GOOD_D';

  // GOOD END E: 好感度5 + スコア1200-1799
  if (affection === 5 && score >= 1200) return 'GOOD_E';

  // GOOD END C: 好感度4 + スコア1200-1799
  if (affection === 4 && score >= 1200) return 'GOOD_C';

  // GOOD END B: 好感度3 + スコア1200以上
  if (affection === 3 && score >= 1200) return 'GOOD_B';

  // GOOD END A: 好感度2 + スコア1200以上
  if (affection === 2 && score >= 1200) return 'GOOD_A';

  // NORMAL END E: 好感度5 + スコア600-1199
  if (affection === 5 && score >= 600) return 'NORMAL_E';

  // NORMAL END D: 好感度4 + スコア600-1199
  if (affection === 4 && score >= 600) return 'NORMAL_D';

  // NORMAL END C: 好感度3 + スコア600-1199
  if (affection === 3 && score >= 600) return 'NORMAL_C';

  // NORMAL END B: 好感度2 + スコア600-1199
  if (affection === 2 && score >= 600) return 'NORMAL_B';

  // NORMAL END A: 好感度1 + スコア600-1199
  if (affection === 1 && score >= 600) return 'NORMAL_A';

  // BAD END B: 好感度2-3 + スコア<600
  if (affection >= 2) return 'BAD_B';

  // BAD END A: 好感度1 + スコア<600
  return 'BAD_A';
}
```

### 4.2 データ構造

```typescript
interface EndingData {
  id: EndingType;
  title: string;
  subtitle: string;
  theme: string;
  bgColor: string;
  bgMusic: string;
  dialogues: EndingDialogue[];
  hasSpecialCG: boolean;
  unlockCondition: string;
}

interface EndingDialogue {
  speaker: '' | 'かおり';
  text: string;
  expression: KaoriExpression;
  isNarration: boolean;
  choices?: EndingChoice[];
}

interface EndingChoice {
  text: string;
  nextDialogueIndex: number;
}
```
